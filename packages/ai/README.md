# @adhyayan/ai

AI orchestration layer powered by the Vercel AI SDK Core and Upstash Semantic Caching.

## Purpose
- Multi-provider model configuration (OpenAI, Gemini, Claude).
- Streaming token generators (`streamText`) and Structured Outputs (`generateObject`).
- Semantic Cache integration via Upstash Redis to reduce latency and token costs.
- Socratic Teacher and Sarthi Gita Counselor prompt engineering templates.
