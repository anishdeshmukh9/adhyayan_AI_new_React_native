# apps/mobile (React Native / Expo Application)

The cross-platform mobile companion for Adhyayan AI on iOS and Android.

## Key Features
- **Framework**: Expo SDK 54 with Expo Router.
- **UI & Components**: NativeWind / React Native Reusables (Shadcn for mobile).
- **Audio & Media**: Expo AV for AI Podcast listening.
- **Camera & Vision**: Expo Camera & Image Picker for handwritten question scanning.
