# apps/web (Next.js 15 Web Application)

The main desktop and tablet web experience for Adhyayan AI.

## Key Features
- **Framework**: Next.js 15 (App Router, Server Actions, React Server Components).
- **Styling**: Tailwind CSS v4 + Shadcn UI.
- **AI Streaming**: Vercel AI SDK UI (`useChat`, `streamText`) with Generative UI components.
- **Math/Formulas**: KaTeX LaTeX rendering.
